## Purpose

定义 Windows 安装器完成页启动应用的行为：保证从安装器启动的应用不继承安装器的管理员权限，使挂载的盘符对桌面会话可见。

## ADDED Requirements

### Requirement: 完成页以非提权方式启动应用

安装器完成页勾选"运行 RcloneDrive"并点击完成时，安装器 MUST 通过非提权的中转（桌面 shell）启动应用，使应用进程不继承安装器的管理员 token。

#### Scenario: 管理员安装后从完成页启动

- **WHEN** 用户以管理员权限完成安装并在完成页勾选"运行 RcloneDrive"
- **THEN** 启动的 RcloneDrive 进程不带管理员提升标记（任务管理器"已提升"列不为"是"）

#### Scenario: 降权启动的应用可正常挂载

- **WHEN** 从完成页启动的应用执行一次驱动器挂载
- **THEN** 挂载的盘符对当前桌面会话（资源管理器）可见、可访问

### Requirement: 完成页勾选体验保持不变

安装器 MUST 保留完成页"运行 RcloneDrive"的默认勾选交互；本变更只改变启动方式，不新增、不移除完成页元素。

#### Scenario: 完成页元素不变

- **WHEN** 用户进入安装完成页
- **THEN** 页面仍提供默认勾选的"运行 RcloneDrive"选项，行为与历史版本一致（仅启动权限不同）
